# Varun Das - Personal Website

A personal portfolio website showcasing my projects, interests, blog posts, and curated readings. Built with Next.js and featuring an atmospheric, astronomy-themed design.

## Features

- **Hero** – Introduction with social links
- **Now** – What I'm currently working on
- **Projects** – GitHub projects showcase
- **Interests** – Areas of curiosity and exploration
- **Curated Feed** – Articles, books, and links I find valuable
- **Blog** – WordPress blog integration
- **About** – Background and experience
- **Contact** – Get in touch

## Tech Stack

- Next.js 14 (App Router)
- TypeScript
- Deployed on Vercel

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.
